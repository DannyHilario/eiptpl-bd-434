# Base de Datos I y II — Curso continuo

Repositorio del curso de **Base de Datos** impartido con Microsoft SQL Server, con el mismo grupo dando continuidad al curso a lo largo de dos semestres (Base de Datos I y Base de Datos II).

---

## Estructura del repositorio

```
eiptpl-2026-basededatos/
├── bd-1/                  # Semestre anterior (BD-434) — curso completo, ya finalizado
└── bd-2/                  # Semestre en curso — continuación de los mismos temas
```

Cada carpeta tiene su propio `README.md` con la estructura de sesiones, temas y evidencias correspondientes:

- [`bd-1/README.md`](bd-1/README.md)
- [`bd-2/README.md`](bd-2/README.md)

Las convenciones de código SQL, el motor objetivo (SQL Server 2019+) y el alcance temático del curso se definen una sola vez en [CLAUDE.md](CLAUDE.md) y aplican a ambas carpetas.

---

## Requisitos

- [SQL Server 2019 o superior](https://www.microsoft.com/es-mx/sql-server/sql-server-downloads) (Express es suficiente)
- [SQL Server Management Studio (SSMS)](https://learn.microsoft.com/es-es/sql/ssms/download-sql-server-management-studio-ssms)
