## Consulta 1 — Cuentas canceladas ordenadas por fecha de cancelación

**Pregunta:** ¿Qué cuentas han sido canceladas en el banco? Muestra el número de cuenta, el tipo de cuenta y la fecha de cancelación. Ordena de la más reciente a la más antigua.

```sql
SELECT CU.NumeroCuenta, CU.TipoCuenta,
    CU.FechaCancelacion
FROM Cuenta AS CU
WHERE CU.Activo = 0
ORDER BY CU.FechaCancelacion DESC
```

**Explicación:**

- `WHERE CU.Activo = 0` — la columna `Activo` es de tipo `BIT`. El valor `0` identifica las cuentas canceladas y el valor `1` las cuentas vigentes. Filtrar por `0` descarta todas las cuentas que siguen activas.
- `SELECT CU.NumeroCuenta, CU.TipoCuenta, CU.FechaCancelacion` — se piden exactamente las tres columnas del enunciado. La columna `FechaCancelacion` solo tiene valor cuando `Activo = 0`; para las cuentas vigentes ese campo es `NULL`.
- `ORDER BY CU.FechaCancelacion DESC` — `DESC` coloca la cancelación más reciente primero. Omitirlo invierte el orden o lo deja indeterminado.

**Error frecuente:** Usar `Activo = 1` en lugar de `Activo = 0` devuelve las cuentas activas, que es lo opuesto a lo solicitado.

## Consulta 2 — Reporte de retiros con cliente y número de cuenta

**Pregunta:** Genera un reporte de todos los retiros. Muestra nombre del cliente, apellido paterno, número de cuenta, monto y fecha. Ordena de la transacción más reciente a la más antigua.

```sql
SELECT C.Nombre, C.PrimerApellido,
    CU.NumeroCuenta, T.Monto, T.FechaTransaccion
FROM Transaccion AS T
    INNER JOIN Cliente AS C ON C.idCliente = T.idCliente
    INNER JOIN Cuenta AS CU ON CU.idCuenta = T.idCuenta
WHERE T.TipoTransaccion = 'Retiro'
ORDER BY T.FechaTransaccion DESC
```

**Explicación:**

- `FROM Transaccion AS T` — la tabla principal es `Transaccion`, porque es donde están los movimientos bancarios.
- `INNER JOIN Cliente AS C ON C.idCliente = T.idCliente` — `Transaccion` guarda el `idCliente` de quien realizó el movimiento, pero no el nombre. El `INNER JOIN` conecta `Cliente` para recuperar `Nombre` y `PrimerApellido`. Solo se incluyen las transacciones que tienen un cliente coincidente.
- `INNER JOIN Cuenta AS CU ON CU.idCuenta = T.idCuenta` — `NumeroCuenta` vive en `Cuenta`, no en `Transaccion`. Se agrega un segundo `INNER JOIN` para traer ese dato usando `idCuenta` como columna de unión.
- `WHERE T.TipoTransaccion = 'Retiro'` — filtra para quedarse solo con los retiros. El texto debe escribirse exactamente como está almacenado.
- `ORDER BY T.FechaTransaccion DESC` — el retiro más reciente aparece primero.

**Por qué se necesitan 3 tablas:** El nombre del cliente está en `Cliente`, el número de cuenta en `Cuenta`, y el movimiento en sí en `Transaccion`. Sin los dos `JOIN`, la consulta solo puede mostrar los IDs numéricos, no los datos legibles.

## Consulta 3 — Cuentas sin ninguna transacción

**Pregunta:** ¿Qué cuentas no tienen ninguna transacción registrada? Muestra el número de cuenta y el tipo de cuenta. Ordena por número de cuenta.

```sql
SELECT CU.NumeroCuenta, CU.TipoCuenta
FROM Cuenta AS CU
    LEFT JOIN Transaccion AS T ON T.idCuenta = CU.idCuenta
WHERE T.idTransaccion IS NULL
ORDER BY CU.NumeroCuenta
```

**Explicación:**

- `LEFT JOIN Transaccion AS T ON T.idCuenta = CU.idCuenta` — el `LEFT JOIN` conserva **todas** las cuentas, incluso las que no tienen transacciones asociadas. Para esas cuentas, las columnas de `Transaccion` aparecen como `NULL`.
- `WHERE T.idTransaccion IS NULL` — identifica las cuentas que no encontraron ninguna coincidencia en `Transaccion`. Si `idTransaccion` es `NULL`, esa cuenta no tiene movimientos. Se usa `IS NULL` porque los valores nulos no se pueden comparar con el operador `=`.
- `ORDER BY CU.NumeroCuenta` — ordena alfanuméricamente por número de cuenta en sentido ascendente (valor por defecto).

**Diferencia con A1 y A3:** En A1 y A3 se buscan *clientes* sin transacciones uniendo `Cliente` con `Transaccion` por `idCliente`. En esta versión se buscan *cuentas* sin transacciones uniendo `Cuenta` con `Transaccion` por `idCuenta`. El patrón es el mismo, cambia la tabla de la izquierda y la columna de unión.
